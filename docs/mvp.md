# MVP — первая версия

Документ фиксирует scope первой рабочей версии для защиты диплома.

---

## Продукт (Chat API + Desktop)

### Входит в MVP

| Функция | Описание |
|---------|----------|
| Регистрация и вход | Без лимитов на количество аккаунтов с одного устройства |
| Список контактов | Добавление контактов |
| Чат 1-на-1 | Личные сообщения с E2E-шифрованием |
| Статусы сообщений | Отправлено, доставлено, прочитано |
| Присутствие | В сети / не в сети |
| Индикатор набора | «Печатает…» |
| Локальный поиск | Поиск по своим чатам и сообщениям — **только на клиенте** |

### Не входит в MVP

- Групповые чаты и серверы/каналы
- Рейтинг и репутация
- Жалобы и арбитраж
- Голос, стримы, ML-модерация
- Экономика, монеты, KYC, маркетплейс
- Автоматические баны и блокировки регистрации
- Скрытый risk score
- Поиск пользователей через сервер

## Центр Безопасности

### Входит в MVP

| Функция | Описание |
|---------|----------|
| Приём событий | От Chat API по gRPC (`IngestEvent`) |
| Фиксация связей | Между аккаунтами в собственной БД |
| Типы связей | `same_device`, `shared_contact`, `communicates_with` |
| Admin API | Отдача таблицы связей в интерфейс администратора |
| Админка | Таблица: Аккаунт A — Аккаунт B — Тип — Вес — Дата |

### События, которые принимает Центр

| Событие | Когда | Данные |
|---------|-------|--------|
| `user.registered` | После успешной регистрации | `user_id`, `device_hash` |
| `user.logged_in` | После успешного входа | `user_id`, `device_hash` |
| `contact.added` | После добавления контакта | `user_id`, `contact_id` |
| `message.sent` | После сохранения ciphertext | `from`, `to`, `message_id`, `timestamp` |

**Не передаётся:** текст сообщения, ciphertext, private keys.

### Не входит в MVP (Центр Безопасности)

- Скрытый скоринг
- Автоматические баны
- Поиск паттернов абуза
- События «кто кого искал»
- Presence и typing (остаются только в Chat API)

### Философия MVP

> Сначала копим данные по связям и смотрим, что получается. Правила и enforcement — фаза 2.

---

## E2E (дипломный минимум)

- Шифрование личных сообщений 1-на-1 (Double Ratchet).
- Групповые чаты — **Roadmap** / stretch goal, не блокер защиты.

---

## Минимальная инфраструктура (не диплом, но обязательна)

| Компонент | Зачем |
|-----------|-------|
| `users` | Регистрация, вход, контакты |
| `gateway` | gRPC entrypoint Chat API |
| `e2e` | Prekeys, отправка/получение ciphertext |
| `security-center` | Граф связей, admin API |
| `desktop` | UI: регистрация, чат, контакты, статусы, presence |
