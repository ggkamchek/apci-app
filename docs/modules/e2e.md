# Модуль E2E-шифрования

**Владелец:** Петя  
**Server:** `server/internal/e2e`  
**Desktop:** `desktop/internal/crypto`

---

## Назначение

Обеспечить конфиденциальность личных сообщений. Сервер не имеет доступа к plaintext и private keys.

---

## MVP scope

| Входит | Не входит |
|--------|-----------|
| 1:1 чат с E2E | Групповые чаты (Roadmap) |
| Double Ratchet сессия | Серверы / каналы |
| Обмен prekeys (X25519) | |
| Хранение ciphertext на сервере | |
| Локальный поиск по чатам | Серверный поиск по содержимому |
| Статусы: sent / delivered / read | |

---

## Криптография

| Параметр | Значение |
|----------|----------|
| Протокол | Double Ratchet (Signal Protocol) |
| Обмен ключами | X25519 (ECDH) |
| Шифрование сообщений | AES-256-GCM |
| Где шифруется | На клиенте (desktop) |

---

## Что хранит сервер

| Данные | Хранение |
|--------|----------|
| Public prekeys | ✅ |
| Ciphertext | ✅ |
| `message_id`, `chat_id`, `sender_id`, `recipient_id` | ✅ |
| `timestamp`, `size` | ✅ |
| Private keys | ❌ |
| Plaintext | ❌ |

Метаданные доставки (`from`/`to`) также используются Chat API для отправки события `message.sent` в Центр Безопасности — без содержимого сообщения.

---

## Ключи и восстановление

- Private keys хранятся **только на устройстве пользователя**.
- Сервер **не может** восстановить ключи или историю при утере устройства.
- Резервное копирование ключей на сервере — **не предусмотрено**.

**Roadmap:** опциональный encrypted backup-файл, экспортируемый пользователем локально.

---

## Локальный поиск

Индекс для поиска по сообщениям строится на клиенте после расшифровки. Сервер не выполняет поисковых запросов по содержимому.

---

## Задачи реализации

1. Реализовать Double Ratchet на desktop (Go).
2. Интегрировать шифрование/расшифровку в UI чата.
3. Server: API загрузки prekeys, приём и выдача ciphertext.
4. Установка сессии между двумя пользователями.
5. Локальный поиск по расшифрованной истории.

---

## Зависимости

- `users` — идентификация участников (`users.id`)
- `gateway` — gRPC endpoint
- Chat API отправляет `message.sent` в Центр Безопасности (без ciphertext)
