# APCI — обзор платформы

**Репозиторий:** `apci-app` (монорепо)  
**Клиент:** десктопное приложение (Wails)  
**Backend:** Go  
**Протокол:** gRPC (Protocol Buffers)

---

## Концепция

**APCI** — десктопная коммуникационная платформа, построенная на принципах **архитектурной приватности**. Приватность — не настройка, а свойство системы: платформа не должна иметь технической возможности читать личные данные пользователей или передавать их третьим лицам.

Философия: *«Мы не можем отдать, продать или потерять то, чего у нас нет»*.

---

## Возможности платформы (полное видение)

| Область | Описание |
|---------|----------|
| Текстовые чаты | Личные сообщения, групповые чаты, публичные каналы |
| Голос | Живое общение без записи; медиасервер маршрутизирует UDP |
| Видео-стриминг | Публичные и приватные стримы без сохранения на диск |
| Экономика | Внутренняя валюта: донаты, маркетплейс, оплата услуг |
| Репутация и арбитраж | Социальные очки, слепой арбитраж жалоб |
| Маркетплейс | Торговля цифровыми товарами |
| Безопасность | Центр Безопасности: граф связей, выявление мультиаккаунтинга |

Что уже реализовано и что в планах — [roadmap.md](./roadmap.md).

## Ключевые модули

| Модуль | Назначение | Путь |
|--------|------------|------|
| E2E-шифрование | Конфиденциальность переписки | `server/internal/e2e`, `desktop/internal/crypto` |
| Центр Безопасности | Граф связей, antifraud | `security-center/`, `desktop/internal/fingerprint` |
| Users | Регистрация, аутентификация, контакты | `server/internal/users` |
| Gateway | gRPC entrypoint Chat API | `server/internal/gateway` |

Склейка модулей — через `users.id`. Private keys и plaintext сообщений **только на клиенте**.

## Модерация (контекст продукта)

Модерация вмешивается только при жалобе участника или при детектировании грубейших нарушений в публичном стриме.

- **Красная зона** — немедленная блокировка (угрозы, эксплуатация детей, доксинг, мошенничество).
- **Обычные нарушения** — нарастающая шкала: предупреждение → мут → снижение репутации → временный бан → перманентный бан.
- **Слепой арбитраж** — арбитр видит обезличенный фрагмент; расшифровка только с согласия жалобщика через временную арбитражную сессию.

Реализация модерации и арбитража — **этап 3** roadmap, см. [roadmap.md](./roadmap.md).
